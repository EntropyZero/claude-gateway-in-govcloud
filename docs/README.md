# docs/ — what lives where

| Folder | Contents | Audience |
|---|---|---|
| [`ato/`](ato/) | The ATO/review package: [`architecture.md`](ato/architecture.md) (diagrams + secrets/SG/encryption inventories), [`conops.md`](ato/conops.md) (Concept of Operations), [`network-access-controls.md`](ato/network-access-controls.md) (who-can-talk-to-what deep dive), [`security-review-2026-07.md`](ato/security-review-2026-07.md) (finding-by-finding status — **the source of truth** for what's done and the running fix log), [`security-review-2026-07-resubmission.md`](ato/security-review-2026-07-resubmission.md) (the point-in-time assessment for the resubmission: methodology, accepted risks, verified strengths, 27 confirmed findings, verification ledger), and `diagrams/` (hand-laid-out SVGs generated by [`ato/diagrams/generate.py`](ato/diagrams/generate.py) — edit the script, re-run, commit both; never Mermaid) | Security reviewers / AO |
| [`operations/`](operations/) | Operator docs: [`greenfield-deployment.md`](operations/greenfield-deployment.md) (**start here** — empty VPC → authenticated client, incl. the org-prerequisite request phase), [`om-runbooks.md`](operations/om-runbooks.md) (steady state: rotation, updates, alarms, backup/restore, teardown), [`cost-controls.md`](operations/cost-controls.md) (spend caps, dashboards, fail-closed incident response), [`client-config.md`](operations/client-config.md) (Part I: developer user manual — prerequisites, install, sign-in, troubleshooting; Part II: managed-settings enforcement model), [`monitoring-and-retention.md`](operations/monitoring-and-retention.md) (alarms, SNS notification contract, every log/metric destination with retention + encryption), [`test-run-runbook.md`](operations/test-run-runbook.md) (the dated 2026-07 first-test-run log, kept for its verification annotations) | Operators |
| [`requests/`](requests/) | Copy-paste request templates for the org teams whose actions gate a deploy: [`networking-request-email.md`](requests/networking-request-email.md) (cert/DNS/Zscaler), [`okta-request-email.md`](requests/okta-request-email.md) (OIDC app + groups claim), [`ad-request-email.md`](requests/ad-request-email.md) (GPO managed setting) | Operators → org teams |
| [`generated/`](generated/) | The PDF renderings of the review package (architecture, network-access-controls, om-runbooks, conops). Regenerate with `make docs-pdf` ([`md-to-pdf.py`](md-to-pdf.py), needs `weasyprint`+`markdown` from `scripts/requirements-tools.txt`) in the same change that edits a source doc or diagram. | Reviewers who want files, not markdown |

The PDF set is exactly `architecture.md`, `network-access-controls.md`,
`conops.md`, `om-runbooks.md`, `cost-controls.md` (om-runbooks §10
defers to it, so PDF-only reviewers need both), and
`security-review-2026-07-resubmission.md` (the point-in-time assessment —
unlike the living review log, it is a submission document). The living
security review, `client-config.md`, the other runbooks, and the request
templates are deliberately not in it.
